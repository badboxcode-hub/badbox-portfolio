# badbox — перенос на GitHub Pages

Подготовлено для аккаунта badboxcode-hub. Публикация и подключение badbox.art ещё не выполнены.

## Состав

11 страниц: главная, список проектов, шесть проектов, список статей и две статьи. Списки проектов и статей собраны из карточек сохранённой главной. Изображения, 7 видео, шрифты, иконка и изображение для социальных сетей сохранены локально. Для работы сайта не нужен Framer или сборка JavaScript.

## Проверено

- 82 внутренние ссылки и 196 подключений ресурсов ведут на существующие файлы.
- Русский текст корректно отображается в UTF-8.
- Главная и Tamburins просмотрены в браузере на ширине 1280 пикселей.
- Главная проверена в окне шириной 390 пикселей: горизонтального переполнения нет, блок навыков раскрывается.
- Видео Tamburins загружает метаданные и кадры без ошибки.

Полная визуальная проверка всех страниц и воспроизведение всех видео пока не завершены.

## Отличия от Framer

Служебные скрипты Framer удалены. Появление карточки и поворот крепления восстановлены по сохранённым параметрам Framer. Появление букв, раскрытие навыков, появление карточек при прокрутке и реакции на наведение реализованы собственным небольшим скриптом. Системная настройка уменьшения движения отключает эффекты; при отключённом JavaScript содержимое остаётся видимым. Вместо формы размещена кнопка «Написать на почту», открывающая почтовое приложение. Видео запускаются пользователем и не скачиваются полностью при открытии каждой страницы.

## Публикация

1. Создать публичный репозиторий в аккаунте badboxcode-hub, например badbox-portfolio.
2. Загрузить содержимое этой папки в корень ветки main через Git или GitHub Desktop. Не загружать сам ZIP: GitHub не распаковывает его автоматически.
3. В Settings → Pages выбрать Deploy from a branch → main → /(root) → Save.
4. Проверить тестовую публикацию. Пути работают и в подпапке репозитория, и на собственном домене.
5. После проверки удалить `<meta name="robots" content="noindex, nofollow">` со всех страниц, подключить badbox.art в Pages и настроить DNS.

Некоторые видео больше лимита веб-загрузки 25 MiB, но меньше лимита обычного Git 100 MiB. Поэтому для исходного пакета нужна загрузка через Git/GitHub Desktop. Максимальный размер файла — около 44 MiB.

До завершения проверки домен остаётся на Framer. Canonical, og:url и og:image уже ориентированы на будущий адрес badbox.art; пока домен не переключён, социальный предпросмотр на тестовом домене может быть некорректным.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
